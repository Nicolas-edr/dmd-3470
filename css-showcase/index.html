General Overview

The position property in CSS controls how an element is positioned within the page. With physical properties like top, right, bottom, and left, you can control where an element, or header, is positioned on a page. Positioning is comprosed of 5 values: static, relative, absolute, fixed, and sticky.

Static

The default position for all elements. The inclusion of the top, right, bottom, and left properties have no effect on static elements. This is a position according the the normal flow of the document.

Relative

Positoned in accordance to the normal flow of the document but can be offset using top, right, bottom, and left properties. Like the property name, this offset if relative to itself. Relative positioning does not affect the position of other elemtnets and the spacing for th element in the layout is the same as if it were static.

Absolute

An element with absolute positioning is removed from the normal flow of the document. It is instead positioned relative to its nearest positioned ancestor, if applicable, or relative to the intial contianing block. When this positioning is use,d there is no space created for the element in the normal page layout. The final position is detemrined by the top, right, bottom, and left properties.

Fixed

An element with fixed positioning is removed from the normal flow of the document and there is no space created for it in the page layout. THis element is positioned relative to the viewport, with th efinal position detemrined by the top, right, bottom, and left properties.

Sticky

When an element uses position: sticky, the element is in accordance to the normal flow of the document, then offset. The relative position is determined by the top, right, bottom, and left properties, and relative to the nearest scrolling ancestor. All other elements are not affected by the sticky positioning. This element stays in place, such as a header that remains at the top of the page while scrolling.
